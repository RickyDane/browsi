# Screenshots

Images used by the main [README](../../README.md). Drop images here (WebP, ~quality 90; PNG works too if you update the README) with exactly these names.

**Tips:** take window shots with ⌘⇧4, then Space, then click the Browsi window (⌥-click to skip the shadow).
Use the space theme and a tidy sidebar. About 1600–2000 px wide is plenty; smaller crops are fine for the sidebar
and downloads shots.

## Smart features

| File | What to show |
|---|---|
| `smart-answers.webp` | Home page with a question answered in the search bar (e.g. "What's new in Swift 6?"), with [1] [2] citations visible. |
| `page-assistant.webp` | An article (Wikipedia works well) with the ⌘⇧S panel open: gist, key points, and one follow-up question with an answer and a citation. |
| `find-ask.webp` | The find bar in ask mode (⌘F, then ⌘⇧F) with a question, the one-line answer, and glowing highlights on the page. |
| `translate.webp` | A foreign-language page (e.g. a German or Japanese news site) translated in place, with the translate button in the address bar visible. |
| `page-actions.webp` | ⌘K with the page actions listed, or the editable calendar event card after *Add Event to Calendar* on an event page. |
| `watch-page.webp` | The *Watch Page for Changes…* sheet filled in (e.g. "price below $100", every hour). Optionally add a change notification. |
| `smart-titles.webp` | Crop of the sidebar with a few long-titled tabs shown shortened (docs pages, news articles). |
| `smart-rename.webp` | Crop of the download queue showing a file renamed by Smart Rename. |
